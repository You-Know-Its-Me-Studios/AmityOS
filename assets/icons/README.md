# Amity icon sources

`source/*.svg` are editable sources for the application and desktop icons (Files, Editor,
Terminal, Settings, Browser, Home, folder, project, document). They are original designs
under the accompanying MIT licence. Phase 4 (redesign) keeps only the ones that match the
design screenshots and adds an icon build step.

`source/amity-mask.svg` is an editable transparency mask traced over the supplied
wallpaper; with it, the Amity emblem is cut out of `assets/wallpapers/amity-default.png`.
See [BRAND-SOURCE.md](BRAND-SOURCE.md) for the rights record of that artwork.
